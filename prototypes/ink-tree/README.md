# Living tree scene prototype

CloudInk 三维树形博客的独立交互原型。使用真实 WebGL 场景展示树冠、枝干、叶片和光影；点击入口时，透视相机沿缓动路径靠近对应枝条，内容在同一场景中展开。

## 运行

直接打开 `index.html`，或使用任意静态文件服务器托管本目录。无需构建步骤或 Cloudflare 资源。

三维场景按需从 jsDelivr 导入固定版本的 Three.js 0.180.0（MIT）。首次显示需要联网；树木几何体、树皮和叶片纹理均在浏览器生成，没有额外模型、图片或字体下载。部署方可以在正式集成时将依赖打包到自己的静态资源中。

## 交互

- 树冠入口：随笔、行记、造物、关于、归档。
- 选中枝条后，相机在约 1.45 秒内平滑靠近；阅读面板渐进展开。
- 分类切换和文章阅读复用同一个 WebGL 画布。返回恢复树下的滚动位置，浏览器前进、后退可用。
- 首页沿树干展示倒序文章；滚动带动相机下移，连接线对应文章枝条。
- 独立文章阅读视图、归档、标题/摘要/分类搜索。
- 桌面侧边阅读，手机底部展开；长文使用较大的阅读面板。
- 支持键盘导航、模态焦点约束、Escape 关闭、暂停微风和减少动态效果。
- 轻量阅读可跳过三维模块；导入失败、不支持 WebGL 或上下文丢失时保留文章和导航。

## 渲染与性能

- 叶片采用实例化绘制；枝干合并为一个网格。
- 手机减少叶片数量，限制像素比与帧率，并关闭阴影。
- 连续出现较慢的帧时自动降低分辨率和叶片细节。
- 静态阴影不逐帧重算；标签与连接线只在镜头或滚动变化时更新。
- 页面隐藏、轻量模式和阅读面板中的镜头停稳后停止持续渲染。
- 不依赖背景视频、大幅位图或远程模型。

这些策略用于控制开销，仍需要在真实手机上评估帧率、发热与耗电；云端浏览器检查不能替代设备实测。

## 原型边界

站点题字、分类与文章均为通用演示内容。原型尚未接入 CloudInk 的正式渲染器、后台配置、图片优化或存储结构，也不会修改正式构建与发布流程。

为方便单文件预览，使用 hash 路由（如 `#/post/a-tree-of-words`）在同一场景中演示独立阅读。正式集成应继续生成独立文章 URL、可索引的静态 HTML 和完整无脚本阅读页面；当前无脚本模式仅提供示例文章摘要。

本目录不包含个人账户、域名、存储桶名称或部署凭据。

## 验证

检查桌面和手机视口的布局，以及：

1. WebGL 初始化成功、首屏文章存在、无水平溢出。
2. 点击分类时相机位置随时间改变，停在所选枝条，画布不重建。
3. 分类、文章打开与返回、搜索命中及空结果、归档与关于正常。
4. 返回树下保留滚动位置，浏览器后退恢复前一视图。
5. 暂停微风、轻量模式与返回三维模式可用。
6. 拒绝远程依赖加载时仍可浏览摘要与打开阅读面板。
