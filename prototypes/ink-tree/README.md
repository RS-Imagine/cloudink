# Ink tree prototype

CloudInk 水墨树形博客的独立交互原型。直接用浏览器打开 `index.html` 即可体验，无需安装依赖或配置 Cloudflare。

## 已提供

- 轻量 SVG 树冠、枝干和树叶；浅纸色背景与系统宋体字体栈。
- 树冠内的页面导航与文章分类。
- 按时间倒序的标题、日期和摘要；年份节点和分批显示。
- 桌面左右枝条、手机单侧文章布局。
- 独立阅读视图、关于页、归档、标题/摘要/分类搜索。
- 阅读返回时恢复分类、已展开文章数量和滚动位置。
- 原生链接与按钮、键盘操作、搜索对话框、减少动态效果支持。
- 无外部脚本、字体、图片请求；页面声明不参与搜索引擎收录。

## 范围

这是用于评审外观和交互的设计原型，尚未接入正式渲染器和后台。页面内的站点题字、分类、日期与文章均为示例内容；正式集成时应读取项目内容和网站设置。

为支持直接打开单文件，阅读页使用 hash 路由（如 `#/post/a-tree-of-words`）。正式主题应继续使用 CloudInk 独立文章 URL 和静态 HTML 输出，保留无 JavaScript 时的阅读能力。

本目录不修改正式构建、部署、存储结构或现有网站数据。它不包含账户、域名、存储桶名称或部署凭据。原型的示例文章分批显示不代表已经接入服务端分页；文章图片优化也仍属于后续正式集成工作。

## 验证方式

分别用桌面和手机视口检查：

1. 首屏可看见最新文章标题，页面没有水平溢出，树冠文字与分类按钮不重叠。
2. 点击分类，文章数量与内容对应；查看全部可重置筛选。
3. 打开文章后返回，筛选条件、已展开数量与滚动位置保持。
4. 加载剩余文章，跨年份节点顺序正确。
5. 搜索命中、无结果和特殊字符输入均正常，关闭搜索后焦点可返回。
6. 关于、归档、浏览器前进/后退与键盘导航可用。
