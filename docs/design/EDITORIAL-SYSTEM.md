# 棕褐书刊：公开网站设计规范与实施计划

## 范围与架构

本阶段交付独立网页原型，供视觉与交互审查。原型不参与生产构建，不接入 R2，不改变发布数据。正式实现依托 blog-core 的 Rust 页面渲染、blog-wasm 和现有发布链路；CSS 与必要的原生 JavaScript 负责浏览器展示和交互。不引入前端框架。

原型入口：`prototypes/editorial/index.html`。通过静态 HTTP 服务访问仓库根目录；依赖共享的 `assets/design-tokens.css`。浏览器测试与截图在 GitHub Actions 运行。

## 设计目标

保留 Brown 主题，以衬线标题、舒适正文、留白与细分隔线构成书刊感。首页文章不依赖封面或装饰卡片。导航使用系统无衬线字体，正文采用现有系统衬线栈；中文系统字体缺失时允许系统回退。本阶段不加载中文字体包，跨系统字体差异须在视觉审查时考虑。

本原型共享现有主题变量，未修改生产主题。浅色为暖白与深墨褐；深色为深咖啡与暖灰文字。正文建议桌面 18px、手机 17px，行高 1.95。桌面阅读宽度 720px；900px 以下隐藏侧栏目录；760px 以下切换手机导航。正式实现继续沿用现有移动目录面板，原型暂不复制该业务组件。

## 页面与状态

- 首页：站点导航、介绍、可选枝叶插画、三篇无封面文章、页脚。
- 插画关闭：介绍切换为纯文字构图，没有图片占位。
- 阅读页：作者、摘要、正文、引用、插画、代码与表格、章节目录、复制链接。
- 搜索：标题与摘要匹配、结果数量、无结果提示、原生 dialog、Esc 关闭与焦点恢复。
- 关于：说明原型边界与通用示例。
- 手机：独立导航开关、可读字号、适应窄屏的文章列表。
- 明暗主题、减少动态效果、键盘焦点和跳过导航。

所有文案为项目演示内容。三篇列表链接用于展示不同标题与路由，正文共用阅读样张，不表示三个完整的内容页面。原型不实现生产搜索索引、Swup、Markdown、KaTeX 或图片上传；相关能力在后续集成阶段复用现有实现。

## 插画与资源

`botanical.svg` 为本项目原创的线描枝叶，按项目 MIT 协议提供，不来自参考网站或概念图截图。通过 img 加载，首页装饰使用空替代文本；正文示例提供说明。资源跟随主题背景展示，不改变用户照片颜色。

原型开关只验证布局；正式功能需要独立配置与后端校验，不能将该开关误认为已保存设置。后续提供默认、自定义和不显示三种模式。普通图片复用现有响应式链路，SVG 校验后以图片加载，不注入 DOM。增加引用保护和备份恢复兼容；旧站点缺少字段时默认纯文字，新站点可以选择默认插画。

## 动效

链接与控件 150ms；文章箭头最多平移 3px；原型不持续播放动画。系统减少动态效果时停用平滑滚动与过渡。正式页面切换 180–240ms，优先使用 opacity/transform，并保留现有导航失败处理、滚动恢复和原生链接。

## 参考研究状态

专业案例来源候选为 Awwwards 的博客分类、SiteInspire 和 Godly。本阶段尚未实际访问和审核这些案例，不能视为已完成参考研究；布局依据已确认的原创概念方向。正式视觉定稿前应补充 3–5 个可访问案例及具体借鉴点，不复制源码、品牌或未授权插图。

## 分阶段交付

1. 设计规范、网页原型与云端截图：本 PR。视觉方向仍待人工审查。
2. Rust 模板中的首页、导航、列表、页脚和主题落地；保留链接和无脚本阅读。
3. 首页插画后台设置、校验、引用保护、备份恢复和发布预览。
4. 阅读、搜索、关于、图片交互及编辑预览整合；复用 Swup 与现有浏览器组件。
5. 完整回归、性能比较、无用样式清理、发布与回滚说明。

每阶段独立 PR，基于已明确的上游版本，支持独立 revert。样式需兼容旧的已发布 HTML；模板升级后按现有机制重新发布内容。生产数据与个人配置不进入仓库。

## 验证与验收

云端三浏览器覆盖 1440、768、390、360px，明暗主题、有图与无图。检查页面溢出、插画切换、搜索与焦点恢复、键盘导航、深链、长标题、复制失败反馈和减少动态效果。保存截图、浏览器错误与测量报告以及可下载原型；不新增 Worker，不对生产 R2 测试。

现有项目检查保持运行。本阶段无 Rust 逻辑变更；后续 Rust 修改需在云端执行适用的 cargo fmt、Clippy 和测试，不将已有全仓格式问题夹带进视觉 PR。

截图使用 CI Linux 字体，不能替代真实 iOS、Android 与中文字体环境的最终视觉审查。原型资源体积与浏览器测量属于实验数据，不作为生产 CWV 结论。只有视觉通过后，才将设计接入生产模板。
