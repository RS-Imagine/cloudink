# 棕褐书刊 UI 使用与发布

## 外观

公开首页采用书刊式单列文章列表、衬线标题和细分隔线。文章没有封面时也具有完整布局。网站名称、标题、副标题、作者和页脚继续读取后台设置；升级不会写入示例文案，也不会替换已选主题色。

棕褐 Brown 适合暖白书刊外观；其他现有主题色与读者的明暗模式继续可用。字体优先使用系统字体，具体字形受操作系统影响，不下载大型中文字体包。

## 首页插画

在后台「网站设置 → 网站与外观 → 首页插画」选择：

- 不显示：纯文字首页，旧站点缺少新配置时采用此模式。
- 默认枝叶插画：使用项目原创 SVG。
- 自定义插画：选择图片库中的图片，或上传不超过 256 KB 的 SVG。

普通图片先通过图片库上传，沿用现有压缩与响应式版本。SVG 在上传时校验，通过图片方式显示，不将上传内容注入页面 DOM。替换或关闭插画不会立即删除文件，未使用图片可在图片库清理；仍被保存设置、线上版本或待发布版本引用的资源受删除保护。

后台可预览插画本身。首页完整构图以发布后的页面或独立设计原型为准，后台插画缩略图不是完整网站预览。

## 保存与发布

保存网站设置后，点击发布，才会更新公开首页与已发布页面模板。发布期间保持后台联网并等待完成。升级程序不会自动替用户发布草稿、改变账号或清空存储。

本次增加可选 homeIllustration 设置字段，备份包含配置及上传资源。旧备份缺少该字段时保持纯文字。恢复前检查资源完整性，恢复后按现有流程检查并发布。

## 阅读与交互

标题、引用、图片和搜索浮层使用统一的书刊样式。正文、代码、表格和数学公式延续原有横向滚动与键盘操作。目录、搜索、图片放大、分享、Swup 和编辑预览复用已有实现；系统减少动态效果时简化动画。

## 开发与验证

正式页面由 Rust blog-core 生成，并通过 blog-wasm 使用同一套模板和样式。新增交互使用必要的原生 JavaScript/CSS，不引入前端框架、数据库、新 Worker 或必填环境变量。

自动化验证在 GitHub Actions 的隔离环境运行，使用临时 R2 与通用样张，不连接生产数据。覆盖 Rust/Node 测试、格式和类型检查、构建、dry-run、三浏览器、窄屏、主题、搜索、发布和图片引用保护。修改过的 Rust 文件运行 rustfmt 检查，并执行 Clippy；未把历史上其他模块的格式整理夹带进本次改造。

CI 截图使用安装的中文衬线字体；字体差异与真实触屏设备仍需后续实机确认。独立原型位于 prototypes/editorial，专业参考网站的在线研究状态见 EDITORIAL-SYSTEM.md，不能把未完成的外部研究或实验室数据称为真机验收。

## 回滚

每阶段为独立 PR，可按相反顺序 revert。回滚不删除上传图片、账号和文章。若新版模板已经发布，在回滚程序后按旧模板再次发布网站信息。旧版本忽略可选首页插画字段，配置仍保留在备份中。
