# CloudInk 2.0 设计规范

状态：PR-00 视觉方向已由项目作者确认，PR-01 至 PR-05 已合并，当前推进 PR-06。实现规范随每阶段实测更新。
[四页原型](../../prototypes/ui-2.0/README.md)展示拟采用的比例、层次与交互。
原型保留为已确认的设计参考；PR-01 只接入共享设计基础，布局按后续阶段逐步迁移。

## 视觉方向

**墨绿（建议）**：雾白底、墨绿主色、浅青绿选中面、近黑正文。
暖纸色不再承担全部层次；通过表面明度、留白、形状和少量阴影区分区域。
**中性（比较项）**：保留相同布局，以灰蓝替换主色与选中色。
原型底部“墨绿/中性”按钮可即时比较；两种方案均有明暗主题。

前台保持安静的编辑式阅读节奏；后台使用明确的工作区和稳定工具栏。
连续圆角用于容器，较小圆角用于控件，胶囊只用于状态和分段选择。
避免每个区域都浮起、全屏模糊、彩色正文和持续背景动画。
保留原项目 SVG，不复制 FlClash 的图片、字体、Dart 或 GPL-3.0 实现代码。
程序生成的山形插图是本项目原型的装饰性视觉样本，不要求新增封面图配置。

## 信息架构与断点

| 宽度       | 公开网站                                          | 后台                                          |
| ---------- | ------------------------------------------------- | --------------------------------------------- |
| 0–759px    | 18–20px 页边距、单列、直接搜索/主题入口，目录收束 | 单列工作区、底部主要入口、写作/预览切换       |
| 760–1099px | 28px 页边距；阅读内容优先，空间足够时显示目录     | 88px 图标导航轨、完整可访问名称，工具栏可换行 |
| ≥1100px    | 1160px 内容容器；文章正文上限约 720px、独立目录   | 224px 侧栏；分栏编辑器、稳定顶部操作区        |

断点使用布局可用空间，不按设备品牌判断。实际迁移时以长标题、200% 缩放和
虚拟键盘验证，不将原型的 759/1099 硬编码为不可更改的产品规则。
公开站点原有首页、文章、关于 URL 保留；后台不新增业务路由或数据分类。
原型的分类文案仅为演示排版，后续不能据此新增必填分类、表结构或配置。

公开信息层级：站点身份/导航 → 简介 → 最新文章 → 其他文章 → 页脚。
后台：工作台/文章/图片/设置 → 当前工作区 → 主操作/状态 → 内容。
备份、账号和运行信息属于设置；手机导航仅放高频入口，设置仍需可访问。
编辑器保持标题/摘要/文章属性 → 工具栏 → 正文/预览 → 字数与状态，
保存与发布始终清晰区分，不因动画替换真实服务端状态。

## 正式首页与导航（PR-03）

`crates/blog-core/src/assets/home.css` 负责正式阅读站点的壳与首页；通过 Rust 共享样式嵌入，
不新增样式请求。首页沿用原型的介绍区、作者标记、纸笺、最新文章大卡与后续三列卡片。
桌面三列、平板两列、手机单列；最新卡只使用程序生成的装饰山形，不读取上传封面，
不增加分类、阅读时长、封面或部署配置字段。文章使用原有已发布顺序，每篇只出现一次。

页眉展示现有 SVG 与作者设置的站点名称，主内容保留唯一 h1；长站名在页眉紧凑显示，
完整名称保留在链接文本、title 与元信息中。正文标题与摘要自然换行，不截断。
手机始终可访问搜索与明暗切换，原生 details 菜单支持无脚本、键盘、Esc/焦点恢复、
外部点击与页面切换收起；Swup 页面更新后同步 aria-current。
SSR 已输出导航状态、文章链接与主题色，无需先请求设置。
页脚保留作者自定义文字，提供项目链接与浏览器明暗偏好入口。
文章正文、目录与搜索内容布局保留，按 PR-04 单独改造。

## Token 单一来源方案

正式 Token 唯一来源为 [assets/design-tokens.css](../../assets/design-tokens.css)，
基础控件规则为 [assets/design-foundation.css](../../assets/design-foundation.css)。
Rust `render::stylesheet()` 在编译期嵌入这两份源；后台 `build-ui.mjs`
在构建期拼接同一份源。原型的 tokens.css 通过相对 @import 引用共享 Token。
预览沿用 Rust 样式，公开样式哈希包含 Token 内容；不增加 CSS 请求或远程字体。

[assets/theme.js](../../assets/theme.js) 是唯一正式主题控制器，分别以公开 /theme.js、
后台 /admin-theme.js 的现有资源 URL 提供，且在样式前执行。
原生 Rust 输出内联同一源；Worker 发布清洗器改用同源外部脚本。
已选浅/深或系统主题在首次绘制前恢复，CSS 在无脚本时仍跟随系统。

主题色由作者设置 `themePalette`：`ink`（默认墨绿）或 `neutral`（中性灰蓝）。
缺少该可选字段的已有配置与备份保持可用；不新增资源、环境变量或设置文件。
后台保存后同步后台与预览，发布后由 Rust 在所有公开页 HTML 输出 data-palette；
Swup 导航从新页面同步配色，无需先请求配置接口。保存不会提前改变公开站点。
后台本机缓存仅减少刷新闪烁，登录后的已保存设置覆盖它，公开页不读取该缓存。

明暗模式属于浏览器：沿用 localStorage.theme，值为 auto/light/dark，跟随系统可重新启用；
两个窗口同步同一浏览器偏好。禁用存储时仍可切换，刷新回到系统模式。
作者发布不能覆盖读者选择的明暗模式；预览跟随后台的配色与明暗。

命名采用 --ci-*；逻辑映射如下：

## 排版与内容

UI 默认 15–16px，次级说明 12–13px，不将关键状态缩成装饰文字。
中文阅读正文 17–18px，行高约 1.9；英文与长链接使用自然换行和 overflow-wrap。
标题允许断行，不截断读者需要理解的信息。后台文章列表可在不丢失可访问名称时截断。
代码使用独立等宽字体并可键盘横向滚动；数学和表格保留语义与原有渲染管线。
原型预览只做安全的文本/标题/引用示意，不实现新的 Markdown 引擎。

## 组件契约

共通状态：Default、Hover、Pressed、Focus-visible、Selected（适用时）、
Disabled（真实 disabled/aria-disabled 与事件保护）、Loading、Success、Error。
所有提交按钮 loading 时保留尺寸、可理解名称和 aria-busy；结果有就近文字/状态区。

| 组件                 | 外观/尺寸                           | 行为与可访问性要求                                       |
| -------------------- | ----------------------------------- | -------------------------------------------------------- |
| Button               | 44px 高、14px 圆角，主/轻/中性/危险 | 明确主操作，等待时防重复提交；按压不移动布局             |
| IconButton           | 44×44px，20px 线性图标              | aria-label；不只依赖 title；键盘触发                     |

## 动效契约（PR-02）

正式工具为 [assets/motion.js](../../assets/motion.js) 与 [motion.css](../../assets/motion.css)。
Rust 的原生 client_script() 与浏览器构建嵌入同一源，后台通过 esbuild 打包同一源，
不新增脚本请求或运行时依赖。原型的短 CSS 按压反馈仅展示意图；
[独立动效演示](../../prototypes/ui-2.0/motion.html)使用正式工具，解压审阅包即可操作。

固定过渡用于颜色、淡入和非手势位移。按钮使用质量 1、刚度 420、阻尼 34 的真实弹簧，
目标缩放 0.965，松开后回到 1；重定向保留当前速度，显式释放速度可由后续手势提供。
当前未实现拖拽手势，其速度采样属于 PR-07。
后台内容切换仅做轻微淡入，不移动输入框或替换编辑 DOM；Toast 与原生 Dialog 使用可取消的进出过渡。
公开搜索的 CSS 过渡与 Swup 页面过渡使用统一 Token。
真实弹簧需要状态 x、速度 v、目标 target、质量 m、刚度 k、阻尼 c：
m*x'' + c*x' + k*(x-target)=0。
换目标时保留 x/v；pointer release 提供采样初速度；按 dt 求解，长时间间隔要限步。
优先精确解析解或稳定积分，不让大 dt 导致爆炸，不每帧创建对象或测量布局。
初始建议：小控件 m=1、k=420、c=34；Sheet m=1、k=300、c=32，均需实测校准。
退出与进入可取消/反向；完成回调不能覆盖更晚的状态，统一取消句柄。
系统减少动态效果时直接落终态，关闭大位移与交错，保留状态和操作反馈。
前台 Swup 导航、浏览器返回/滚动恢复使用同一清理/取消周期，避免重复监听与弹层残留。

正式 API：CloudInkMotion.mount() 安装一次委托监听，spring({ from, mass, stiffness, damping, onUpdate, onComplete })
返回 to(target, velocity?)、jump(value)、stop()；解析解覆盖欠阻尼、临界与过阻尼。
enter/exit(element, { kind, signal, onFinish }) 返回 finished（完成 true、取消 false）与 cancel()；
重定向从当前视觉状态继续，旧回调不能覆盖新状态。openDialog/closeDialog 保留原生焦点、Esc 和 close 事件。
cancelWithin(root) 清理组件范围的过渡与按压；独立创建的业务 spring 由调用者 stop()。
visibilitychange 暂停时间，页面离开与 Swup 导航清理动效；一个 rAF 仅在弹簧活动时运行。
动画每帧不测量布局；WAAPI 重定向只在交互触发时读取当前合成样式。
不支持 WAAPI 时立即完成过渡，不支持 individual scale 时保留原生按钮行为。

PR-08 再评估玻璃：先比不透明与轻量 backdrop-filter，再决定有无必要使用 Shader。
原型当前使用不透明表面；未实现手势弹簧、真实折射或生产导航过渡。

## 可访问性与性能门槛

正文/按钮文字按 4.5:1，大字与非文本必要边界按 3:1 相关要求审查；
自动化只验证 Token 常用组合，不能代替完整 WCAG 2.2 AA 审计。
项目目标为主要触控入口至少 44px；这高于 WCAG 2.2 AA 2.5.8 的 24px 最低要求，
不能把 44px 写成 AA 强制门槛。焦点不被浮动导航遮挡，200% 缩放与长文本需人工复核。
dialog 的关闭/结果焦点回归需桌面与触屏验证；不制造焦点陷阱。

PR-00 升级前资源见基线报告；PR-01 的正式包变化与原型资源分别记录在 CI 报告。
PR-01/02 的起始预算：共享 Token gzip ≤4KiB，动效工具 gzip ≤4KiB，无新增运行时依赖；
最终数值以构建报告和当前功能对比为准。禁止持续空闲 rAF，
玻璃/弹簧的帧耗时、耗电、软键盘及真机滚动在对应阶段验收。

## 正式阅读与搜索（PR-04）

正文采用 720px 上限与 18px/1.95 的阅读字体；手机为 17px。
1100px 起使用右侧 200px 目录，低于该断点使用已有浮动目录入口；拖拽与停靠留在 PR-07。
布局预留目录列，正文加载图片、字体或尺寸变化时重新缓存标题位置；滚动帧只查找位置缓存，
当前章节变化时才更新链接状态，不维持空闲渲染循环。重复标题与已有页面 ID 冲突时分配独立锚点，
初次/跨页深链在生成 ID 后定位；历史访问在 Swup 内容替换后恢复位置；按现有 history index 保留最多 100 个内存位置，不增加持久化设置。
手机目录支持 Escape、关闭按钮、循环焦点和背景 inert，选中目录后焦点进入标题。

搜索使用原生 dialog 与共享动效，保留旧版非 dialog 模板的运行时回退。
显示加载、最近文章、匹配数量、无结果和失败重试说明；无关键词时最多展示五篇，
搜索最多十篇，标题与摘要/正文片段全部以文本节点和 mark 高亮构建。
输入期间的首次请求在快速关闭/重开时复用，下载完成后按当前输入重新匹配。
方向键选择、Enter 打开、Escape 关闭，支持 Ctrl/Cmd+K 或非输入区域的 / 快捷键。
搜索不改动索引格式、发布管线或持久化设置。

引用、代码、表格、图片预览和分享表面复用现有语义 Token；不引入玻璃、字体或图片请求。
后台预览继续嵌入同一 Rust 样式；隐藏站点页眉/页脚而保留文章标题区，
预览列单独展开正文并按实际视口断点排版。自动检查在相同视口宽度比较预览/公开正文的字体、
字号和行高，而非要求不同列宽有相同响应式字号。
阅读时长仅按中日韩文字约 400 字/分钟及其他单词约 200 词/分钟估计，不保存新字段。

## 正式后台外壳（PR-05）

桌面侧边栏 224px，760–1099px 收为 88px 图标栏；小于 760px 使用底部四入口导航。
保持一份导航 DOM、同一组业务入口和 aria-current，不为移动端复制按钮或事件。
主工作区保留底部安全区和导航空间；这只是基础响应式导航，拖拽与手势在 PR-07 实现。

工作台包括作者问候、开始写作、文章行列表、草稿/已发布筛选及图片/设置入口。
“所有文章”复用列表并隐藏问候与提示区。搜索只筛选客户端已有数据，不新增接口或请求。
文章快速切换改为原生 details；更多操作包括导入、导出和退出。

登录与初始化复用现有字段、验证、请求和两步流程；增加登录等待反馈。

## 正式写作工作流（PR-06）

workflows.css 在现有样式资源末尾拼接，继续使用共享 Token；workflows.js 只负责视图和反馈。
编辑器的工具栏、标题/摘要、文章属性、正文/预览、字数与危险操作具有稳定分区。
桌面提供写作/分栏/预览，窄屏提供写作/预览；偏好只保留在当前页面内存。
切换通过 CSS 隐藏既有 DOM，不替换 textarea、iframe 或草稿，不改变选区与输入。
只有预览可见时才请求排版；保存、并发保护和当前文章导航仍使用原有函数。

图片库以固定比例缩略区、元信息、引用状态与操作区展示素材，按钮至少 44px。
加载失败显示错误与重试，不把失败误报成空图库；删除仍由服务端引用检查、ETag 和作者确认保护。
引用错误与操作结果保留文字说明，不仅靠颜色；原始图片内容、传输和存储格式均不变。

设置按网站与外观、账号、备份与恢复、运行信息分组，保留原生表单、select 与锚点导航。
保存网站信息、账号更新和备份失败在就近状态区持续显示；发布状态继续由真实发布流程驱动。
网站设置保存不会提前修改公开站点。主题色仍使用既有 themePalette 字段。

删除、取消发布、覆盖原稿与恢复使用统一原生 dialog，明确操作后果、危险按钮和取消。
默认焦点在取消，Esc 等同取消，关闭后恢复原触发点；动画复用 CloudInkMotion。
不支持 dialog 的环境保留浏览器 confirm 回退；未确认时不启动数据操作。
图片放大复用原生 dialog 的焦点与关闭行为，所有弹窗保持明确标题与关闭入口。
本阶段不实现拖拽、停靠或玻璃，也不引入新的资源请求、依赖、数据字段或服务。
