# 概念图对齐：棕褐书刊

本轮验收目标是用户确认的「棕褐 · 编辑刊物」概念图。此前网页原型和自动测试通过不等于该图的视觉验收；历史 UI 2.0 原型不是当前目标。

## 正式实现

- 首页：紧凑刊头与邻接导航；两栏文字/植物构图；宋体大标题、斜体副标题、介绍文字；文章用日期栏、标题/摘要、可选缩略图和细分隔线构成。
- 文章：较窄正文、侧栏目录、清晰的衬线标题与引用，不给正文添加大卡片。
- 后台：同一纸色与字体；目录式侧栏、纸面编辑器、联系印图库和编号设置章节。后台不在原始概念图中，使用相同视觉语言延展，不宣称逐像素复刻。
- 网站配置、作者、标题和文章保持用户内容。截图里的样张仅属于测试。
- 插画仍为默认/自定义/关闭。原有关闭设置不被升级覆盖。

## 字体与资源

Noto Serif SC 由 Fontsource 5.3.1 提供，按 SIL OFL-1.1 保留许可证。构建复制 400/600 字重的 WOFF2 Unicode 分片至同源静态资源，浏览器按字符加载，font-display: swap 保证文字可先阅读；不用 Google Fonts 或字体 CDN。不把字体塞进 Worker JavaScript 或 R2。系统字体是下载失败时的回退，不能作为正常验收结果。

默认植物图是项目原创 SVG，补充叶脉、细线刻画和花簇。它还需以真实浏览器截图进行目视验收，不将代码存在等同于概念图相符。

文章缩略图来自正文第一张安全的托管 Markdown 静态图片；无图文章没有空占位。外链、HTML 内嵌图片和 GIF 不自动提升为首页图。沿用图片响应式衍生版本、明确 sizes、固定比例和懒加载；图片本身不增加第二个文章链接。

## 验收

云端运行 Rust 格式/测试、Node 测试、构建与三浏览器检查。1440/390/360px、Brown 明暗主题、插画开/关、有图/无图、长标题、键盘和减少动态效果均应有实页截图。字体检查应确认网络加载与实际 FontFace 状态，不能靠 CI 预装字体冒充自托管成功。

不得在生产 R2 测试或创建测试 Worker。模板变更需现有发布流程重新生成文章；不能用“重新发布”解释尚未实现的视觉。公开页面、编辑器与全部后台页面目视审查未完成前，本轮保持 Draft。
