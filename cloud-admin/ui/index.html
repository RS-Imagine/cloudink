发布连接

首次设置步骤
  1. 在 Cloudflare 打开 Workers & Pages → r-blog。
  2. 进入 Settings → Builds → Add deploy hook。
  3. 名称填 online-admin，分支选择 master。
  4. 复制生成的链接，粘贴到下方并保存。

链接只用于触发部署，请在这里输入，无需发送到聊天里。
