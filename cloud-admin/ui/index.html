网站与外观

外观
网站图标

支持 SVG / ICO，最多 256 KB。SVG 会移除脚本、外部资源和嵌入内容。公开网页的标签页与页头共用此图标，上传文件可在图片库管理。

主题色

保存后应用到后台和预览；发布网站信息后，公开网页统一更新主题色。

明暗模式只影响当前浏览器。读者可以自行选择，不会强制跟随后台。

视觉效果根据浏览器和设备自动选择，只影响当前浏览器；选择简洁可关闭透明效果。

外观与关于页面
访问统计（可选）

默认关闭。填写 Microsoft Clarity 项目 ID 后，发布网站信息以启用统计。

一个作者，一处安心的写作空间。

修改邮箱或密码需要验证当前密码。修改后，其他设备的登录会失效。

03

备份与恢复

为写下的每一篇，留一份副本。

下载一份包含网站设置、文章原稿和上传图片的 ZIP 备份。备份包含未发布的文字，请妥善保存。

恢复为草稿与待发布设置，不修改登录账号或当前线上版本；检查后再发布。相同内容会跳过，不覆盖已有的不同原稿。
